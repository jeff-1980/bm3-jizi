## 1. `arch_map.md` — extended (§6, appended, nothing above it touched)

Added §6 "Constructive graft (stage 3) — `s4d_plus_gate`: grafting the gate
onto S4D", with:

- **§6.1**: why the gate (not selectivity itself) is the part grafted —
  `z` is already isolated as a single removable part on the selective side
  (`frozen_nogate`, §5b); grafting it onto the never-selective side isolates
  its contribution independent of dt/A/B/C selectivity, which is the point
  of `graft_prereg_provenance.md`'s R statistic.
- **§6.2 gate branch insertion point**: `BearS4D.forward`'s single residual
  line `h = h + layer(ln(h))` (`models_extended.py:223`) is the only line
  `BearS4DPlusGate.forward` changes (via subclass override, not by editing
  `BearS4D` itself) — becomes `h = h + layer(ln(h)) * silu(gate(ln(h)))`.
- **§6.3 z's source projection**: a new per-layer `nn.Linear(d_model,
  d_model, bias=True)` applied to the same `ln(h)` tensor that `_S4DLayer`
  itself consumes as `u` — the S4D analogue of Mamba-3's `z`, which is
  sliced from the same `in_proj(u)` that also produces that layer's `x`/`B`/
  `C` (§1).
- **§6.4 S4D original — zero-change checklist**: a symbol-by-symbol table
  (`_S4DKernel`, `_S4DLayer.__init__`/`.forward`, `BearS4D.__init__`/
  `.forward`/attributes) confirming `models_extended.py` has zero edits —
  every symbol is either inherited via `super().__init__()`/attribute
  access or newly added (`gate_proj` only), never mutated or monkeypatched.
- **§6.5 parameter accounting**: `s4d`=100,162 (verified by direct count
  and by independent `_S4DKernel`/stem/norm/classifier arithmetic, both
  matching); `gate_proj` adds `4 × (64×64+64) = 16,640`; total
  `s4d_plus_gate` = 116,802 (matches `build_model()`'s actual output and
  `graft_unitcheck.json`).
