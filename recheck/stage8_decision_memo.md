## 读法（不改变任何判定标签）

1. **完全冻结的优势（L1f）是最稳的结论**：在独立噪声下三档都显著，幅度与旧协议几乎相同（+21.3 / +23.3 / +20.3，旧协议为 +21.9 / +24.0 / +21.2），种子间方差也最小（sd 1.1–1.9）。
2. **门控的作用依噪声强度而定**：
   - 在完全冻结宿主中，0 和 −2 dB 下拆掉门控后，仍比 S4D 高 14–16 pp，所以这两档的优势**不由门控承载**；
   - 到 −6 dB，拆掉门控损失 32.6 pp，并跌到 S4D 以下 12.3 pp，这一档门控是必需的。
   - 部分冻结宿主（L2）的点估计方向一致（9 / 16 / 27 pp），但 0 和 −2 dB 两档种子方差大（无门控臂 sd 10–16），区间含 0。
   - 这正是审稿意见 #3 预期会暴露的问题：原稿把"完全冻结的优势"和"门控必需"连成一条链，这条链在完全冻结宿主上只在 −6 dB 成立。
3. **加性替换救不回**：两个宿主中加性臂与无门控臂逐点都无差别（区间含 0），配对 ρ 分别为 0.029 [0.011, 0.059] 和 0.194 [−0.002, 0.326]。但因为 L2 和 L2c 是 WEAKENED，按规则判为 not assessable。正文只描述点估计，不使用"未救回"的判定语言。
4. **PU 共享**：门控拆除（L2″）在独立噪声下 HOLDS；部分冻结的优势（L1″）降为 WEAKENED，只有 −6 dB 一档显著。
5. **噪声协议问题的实际影响**：在复核的 8 个臂里，绝对值变化都在 4 pp 以内，方向全部保持。审稿意见 #1 的担忧在实验上**没有改变任何方向**，但改变了两条结论的统计强度（L2、L1″ 从 HOLDS 降为 WEAKENED）。
